# GChecker downloads

GChecker is a private writing helper for Windows that lives in the tray. It checks English and French spelling and grammar in the apps you already write in, and turns Lebanese-style Arabizi (`mar7aba`, `kifak`, `rou2`) into Arabic script. Everything runs on your PC.

## Install

1. Open the [latest release](https://github.com/antokh/GChecker-Update/releases/latest) and download `GChecker-<version>-windows-x64.zip`.
2. Unzip it anywhere and keep the `GChecker` folder together.
3. Open `GChecker.exe`.

Windows 11 x64. No administrator rights needed. The program is not code-signed, so Windows SmartScreen may ask for confirmation the first time.

## Updates

GChecker checks this page for new versions and offers to install them with one click. The smaller files attached to each release (`GChecker.exe` and its checksum) are what the app downloads when it updates itself; you only need the zip for a first install.

This repository holds downloads only.
