# GChecker downloads

GChecker is a private writing helper for Windows that lives in the tray. It checks English and French spelling and grammar in the apps you already write in, and turns Lebanese-style Arabizi (`mar7aba`, `kifak`, `rou2`) into Arabic script. Everything runs on your PC.

## Install

1. Download `GChecker.exe` (about 5 MB) from the [latest release](https://github.com/antokh/GChecker-Update/releases/latest) and open it.
2. Choose **Install GChecker**. It sets up its own folder, downloads its language engine and Java once (about 300 MB), adds shortcuts, and reopens.

Windows 11 x64. No administrator rights needed. The program is not code-signed, so Windows SmartScreen may ask for confirmation the first time.

## Updates

An installed GChecker compares the newest version number here with its own and, when this one is higher, offers to download and install it with one click.

This repository holds downloads only.
