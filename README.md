# GChecker downloads

GChecker is a private writing helper for Windows that lives in the tray. It checks English and French spelling and grammar in the apps you already write in, and turns Lebanese-style Arabizi (`mar7aba`, `kifak`, `rou2`) into Arabic script. Everything runs on your PC.

## Updates

Each [release](https://github.com/antokh/GChecker-Update/releases/latest) carries the GChecker program and its checksum. An installed GChecker compares the newest version number here with its own and, when this one is higher, offers to download and install it with one click.

`GChecker.exe` on its own is an update, not a complete install: it needs the language engine and Java runtime that sit beside it in the GChecker folder.

This repository holds downloads only.
